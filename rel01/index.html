1. INTRODUÇÃO

Esse relatório visa ensinar uma pessoa a criar um relatório no RStudio e publicá-lo na WEB. Para uma pessoa que não possui conhecimentos em programação, o primeiro contato com essas ferramentas pode parecer complicado. Por isso, este relatório tem como finalidade apresentar o processo de maneira simples e passo a passo, explicando desde a criação de um relatório no RStudio até sua publicação em uma página Web. Ao longo deste trabalho, serão apresentados os principais procedimentos para criar o relatório, salvar os arquivos no GitHub utilizando o Git e, por fim, disponibilizar o resultado para que outras pessoas possam acessá-lo pela Internet. Dessa forma, o leitor poderá acompanhar cada etapa mesmo sem possuir conhecimentos prévios de programação.

2. OBJETIVO GERAL

Ensinar, de forma simples e passo a passo, como criar um relatório utilizando o RStudio e como salvar, compartilhar e publicar esse relatório na Internet por meio do Git, GitHub e R, mesmo sem possuir conhecimentos prévios de programação.

3. OBJETIVOS ESPECÍFICOS

  • Apresentar de forma simples o que são o R, RStudio, Git e GitHub;
  • Ensinar a utilizar o editor RStudio;
  • Ensinar como criar e organizar um projeto no RStudio;
  • Ensinar como utilizar o Git para enviar os arquivos para o GitHub;
  • Ensinar a criar uma conta no Github;
  • Ensinar a criar um repositório no Github;
  • Ensinar como publicar o relatório na Internet;

4. FERRAMENTAS UTILIZADAS

4.1 R

Para entender de forma simples, podemos pensar no R como uma ferramenta que recebe informações e executa tarefas a partir de comandos. Por exemplo, podemos fornecer alguns números ao R e pedir que ele calcule uma média, criar gráficos e produzir relatórios.

O R funciona por meio de comandos escritos pelo usuário. Esses comandos informam ao programa o que deve ser feito. Mesmo que no início os códigos possam parecer difíceis, não é necessário saber programação avançada para começar. Com alguns comandos básicos e seguindo um passo a passo, é possível realizar diversas tarefas.

4.2 RSTUDIO

O RStudio é um aplicativo utilizado para trabalhar com a linguagem de programação R. Ele oferece um ambiente organizado onde podemos escrever comandos, executar códigos, visualizar resultados e criar relatórios. Para entender de forma simples, podemos comparar o RStudio com um ambiente de trabalho. Assim como utilizamos um editor de texto para escrever e organizar um documento, utilizamos o RStudio para escrever e executar comandos em R. Dentro do RStudio, é possível criar projetos, escrever códigos, visualizar gráficos, consultar os resultados dos comandos e criar relatórios. Todas essas funções ficam organizadas em diferentes áreas da tela, facilitando o trabalho.

No RStudio foi acessado o caminho: Tools – Global Options – Terminal

E depois selecionar Git bash, e o funcionamento foi confirmado pela identificação MINGW64.

4.3 GIT

Para entender de forma simples, podemos imaginar que o Git funciona como um histórico do projeto. Sempre que fazemos uma alteração importante, podemos registrar essa versão. Dessa forma, conseguimos acompanhar o que foi modificado ao longo do desenvolvimento. Neste trabalho, o Git será utilizado principalmente para registrar as alterações realizadas no projeto e enviar os arquivos para o GitHub.

Adição dos arquivos ao git:

git status
git add .
git commit -m "Initial commit"

4.4 GITHUB

O github pode ser utilizado no navegador, ele é usado para guardar projetos, relatórios, trabalhos acadêmicos e também para publicar na página web. Você cria um perfil e la pode ser mostrado suas atividades e muito mais. É importante entender a diferença entre o Git e o GitHub. O Git é a ferramenta utilizada para controlar e registrar as alterações dos arquivos, enquanto o GitHub é a plataforma online onde esses arquivos podem ser armazenados e compartilhados.

5. CRIANDO UM RELATÓRIO NO RSTUDIO

O processo será explicado passo a passo.

5.1 CRIANDO UM PROJETO

O projeto serve para organizar os arquivos que serão utilizados durante o trabalho. Podemos imaginar o projeto como uma pasta específica para o nosso relatório. Dentro dela ficarão o arquivo do relatório, imagens, códigos e outros arquivos que forem utilizados.

Você deverá copiar a estrutura que foi fornecida pelo professor e colar no repositório criado no RStudio

  • imagens;
  • info;
  • rel01;
  • rel02;
  • rel03;
  • relXX;
  • suporte;
  • index.Rmd;
  • index.html;
  • .gitignore;
  • logo.html.

Passo a passo:

Passo 1 – Abrir o RStudio

Primeiramente, abra o RStudio no computador. Na parte superior da tela, clique em: FILE - New Project…

Será aberta uma nova janela.

Passo 2 – Criar um novo projeto

Na janela que aparecer, selecione: New Directory

Depois, escolha: New Project

Será solicitado um nome para o projeto. Para este exemplo, podemos utilizar:

Profmat_MA41

Em seguida, escolha o local do computador onde deseja salvar o projeto, por exemplo: Disco C.

Depois disso, clique em: Create Project

O RStudio criará uma pasta para o projeto e abrirá uma nova área de trabalho.

Passo 3 – Verificar o projeto

Depois de criar o projeto, é possível verificar que o RStudio está trabalhando dentro da pasta escolhida.

Será criado um arquivo com a extensão:

.Rproj

Por exemplo:

Profmat_MA41.Rproj

5.2 CRIANDO O ARQUIVO DO RELATÓRIO

Depois de criar o projeto, podemos criar o arquivo onde o relatório será escrito. Neste relatório será utilizado o Quarto, que permite criar documentos contendo textos, códigos, resultados, tabelas e gráficos.

Passo 1 – Criar um novo documento

No menu superior do RStudio, clique em: New File - Quarto Document

Uma janela será aberta para configurar o novo documento.

Passo 2 – Informar o título

No campo Title, coloque o título do relatório.

Por exemplo: Como criar um relatório no RStudio

No campo Author, coloque o nome do autor.

Por exemplo: Flavia Alves

No campo Format, selecione: HTML

O formato HTML será utilizado porque o objetivo do trabalho é, posteriormente, disponibilizar o relatório na Web.

Depois, clique em: Create

Passo 3 – Identificar o arquivo

Depois de criar o documento, o RStudio abrirá um novo arquivo na área de edição.

Esse arquivo terá a extensão: .qmd

Por exemplo: Profmat_MA41.qmd

O Profmat_41.qmd será o arquivo principal do relatório. É nele que serão escritos os textos e inseridos os códigos que serão utilizados durante o trabalho.

Passo 4 – Entendendo o início do arquivo

Ao criar o documento, aparecerá uma estrutura parecida com esta:

title: "Como criar um relatório no RStudio"
author: "Flavia Alves"
format: html

Essa primeira parte serve para informar algumas características do relatório.

Define que o relatório será gerado em formato HTML.

Depois dessa parte, podemos começar a escrever o conteúdo do relatório.

Passo 5 – Fazer um primeiro teste

Para verificar se o documento está funcionando, podemos escrever um pequeno texto abaixo das informações iniciais:

Relatório 1

Este é o meu primeiro relatório criado utilizando o RStudio.

O símbolo # antes de uma palavra é utilizado para criar um título.

Nesse exemplo:

Relatório 1

será apresentado como um título no relatório final.

O texto:

Este é o meu primeiro relatório criado utilizando o RStudio.

Na próxima etapa, serão apresentados os códigos em R e como inseri-los no relatório.

Resultado desta etapa

Ao terminar os passos anteriores, teremos uma estrutura semelhante a esta:

Profmat_MA41/
│
├── Relatorio1.Rproj
│
└── Relatorio1.qmd

O arquivo .Rproj representa o projeto do RStudio.

O arquivo .qmd será utilizado para escrever e desenvolver o relatório.

A partir daqui, o relatório já está criado e pronto para receber textos, códigos, resultados e gráficos.

5.3 ADICIONANDO TEXTOS E PACOTES

Depois de criar o arquivo do relatório, podemos começar a adicionar o conteúdo. No RStudio, podemos colocar textos e códigos no mesmo arquivo. Para escrever um texto, basta clicar no arquivo .qmd e digitar normalmente. Por exemplo:

Relatório 1

Este relatório apresenta um exemplo simples utilizando o RStudio.

O símbolo # é utilizado para criar um título.

Para criar um subtítulo, podemos utilizar dois símbolos:

Objetivo

Os pacotes ultilizados e o comando para baixá-los são:

pkgs <- c(
  "rmarkdown",
  "knitr",
  "bookdown",
  "tinytex",
  "postcards",
  "usethis",
  "gitcreds"
)

Para instalar os pacotes, utilize no Console do R:

install.packages(pkgs)
  • usethis, para auxiliar na configuração e integração do projeto com o GitHub;
  • gitcreds, para gerenciamento das credenciais de acesso;
  • rmarkdown, para criação e renderização dos arquivos em R Markdown;
  • knitr, utilizado no processo de compilação dos documentos;
  • bookdown, utilizado na estrutura dos relatórios;
  • postcards, utilizado na página de informações pessoais.

5.4 GERANDO O RELATÓRIO

Depois de escrever os textos e inserir os códigos, podemos gerar o relatório final.

Na parte superior do RStudio, procure pelo botão:

KNIT

Ao clicar nesse botão knit, o RStudio irá executar os códigos e transformar o arquivo .qmd em um relatório.

De forma simples, podemos entender o processo da seguinte maneira:

Texto + Código = RStudio executa = R realiza os cálculos = Relatório final

Como neste trabalho queremos posteriormente publicar o relatório na Internet, utilizaremos o formato HTML.

No início do arquivo .qmd, deve aparecer uma estrutura semelhante a esta:

title: "profmat_MA41"
author: "Flávia Alves"
format: html

indica que o relatório será gerado em formato HTML.

Depois de clicar em knit, será criado um arquivo com a extensão: .html

Por exemplo:

Relatorio1.html

Esse arquivo pode ser aberto em um navegador e apresenta o relatório com os textos, resultados e gráficos que foram adicionados.

Caso seja necessário fazer alguma alteração, basta voltar ao arquivo .qmd, modificar o conteúdo, salvar e clicar novamente em knit.

Na próxima etapa, que será o envio dos arquivos para o GitHub.

Passo 1 – Salvar o relatório

Antes de gerar o relatório, salve o arquivo utilizando: File - Save

O arquivo deve possuir a extensão: .Rmd

Por exemplo: Relatorio1.Rmd

Passo 2 – Clicar em Knit

Na parte superior do RStudio, procure o botão: Knit

Clique nele e escolha: Knit

O RStudio irá executar os códigos e criar o relatório em formato HTML.

De forma simples, podemos entender assim: Arquivo R Markdown – Knit - R executa os códigos - Os resultados são adicionados - Relatório HTML

Depois disso, será criado um arquivo semelhante a:

Relatorio1.html

Esse arquivo é o relatório pronto para ser visualizado em um navegador.

6. SALVANDO O PROJETO NO GITHUB

Agora que o relatório foi criado, precisamos colocar os arquivos na Internet.

Para isso, utilizaremos o GitHub.

Podemos imaginar o GitHub como uma pasta na Internet, onde vamos guardar os arquivos do nosso projeto.

O Git será responsável por registrar as alterações feitas nos arquivos e enviá-las para o GitHub.

O processo será:

RStudio – Git – Github - internet

Para utilizar o Git diretamente pelo RStudio, é necessário que o Git esteja instalado no computador. O RStudio possui integração com Git e apresenta ferramentas para realizar operações como commit, push e histórico.

6.1 CRIANDO UMA CONTA NO GITHUB

Para começar, precisamos ter uma conta no GitHub.

Passo 1 – Acessar o GitHub

Abra o navegador e acesse o site oficial do GitHub:

Passo 2 – Criar uma conta

Na página inicial, procure a opção:

Sign up

Essa opção significa criar uma conta.

Será necessário informar algumas informações, como:

  • endereço de e-mail;
  • senha;
  • nome de usuário.

Depois de preencher as informações solicitadas, siga as instruções apresentadas pelo GitHub.

Passo 3 – Entrar na conta

Depois de criar a conta, faça o login utilizando: Sign in

Agora você estará dentro do seu espaço no GitHub.

A partir desse momento, será possível criar um repositório para guardar o projeto.

6.2 CRIANDO UM REPOSITÓRIO

O repositório pode ser entendido como uma pasta dentro do GitHub.

É nele que vamos colocar os arquivos do nosso projeto.

Passo 1 – Criar um novo repositório

Depois de entrar na sua conta do GitHub, procure a opção:

New repository

O GitHub permite criar um novo repositório diretamente pela página da conta.

Passo 2 – Escolher um nome

No campo Repository name, coloque um nome para o projeto.

Por exemplo: Profmatma41

Podemos também adicionar uma pequena descrição: Relatório criado no RStudio

Passo 3 – Escolher a visibilidade

Será necessário escolher se o repositório será:

Public – qualquer pessoa poderá visualizar o conteúdo.

Private – somente pessoas autorizadas poderão visualizar.

Para este trabalho, será utilizado:

Passo 4 – Criar o repositório

Depois de preencher as informações, clique em: Create repository

Pronto.

Agora temos uma pasta criada no GitHub para receber os arquivos do projeto.

6.3 ENVIANDO OS ARQUIVOS PARA O GITHUB

Agora precisamos enviar os arquivos que estão no computador para o repositório criado no GitHub.

Entre os arquivos, teremos principalmente:

Relatorio1.Rmd

Relatorio1.html

Relatorio1.Rproj

O processo de envio será realizado utilizando o Git.

Passo 1 – Verificar o Git no RStudio

No RStudio, abra o projeto criado anteriormente.

Se o Git estiver configurado corretamente, aparecerá uma aba chamada:

Git

Essa aba permite acompanhar os arquivos que foram modificados e realizar ações relacionadas ao Git. O RStudio possui uma área própria para essas operações.

Passo 3 – Enviar para o GitHub

Primeiramente verificar se no New terminals open with está selecionado o Git bash

Em seguida instale o usethis:

install.packages("usethis")

Depois substitua de acordo com o seu perfil no github:

usethis::use_git_config(
  user.name = "YourName",
  user.email = "your@mail.com"
)

Depois criar o token do github

Execute:

usethis::create_github_token()

Depois coloque o token no .Renviron

usethis::edit_r_environ()

dentro do Renviron coloque:

GITHUB_PAT=ghp_XXXXXXXXXXXXXXXXXXXXXX

e depois do igual apague e cole o token gerado pelo o github e depois pressione enter e depois reinicie o RStudio.

Agora transforma o seu projeto em um repositório git usando o comando:

usethis::use_git()

agora utilize:

usethis::use_github()

esse comando faz a ligação entre o seu projeto local e o GitHub e cria o repositório remoto.

7. PUBLICANDO O RELATÓRIO NA WEB

Agora que os arquivos estão no GitHub, podemos publicar o relatório para que outras pessoas consigam acessá-lo pela Internet.

Para isso, utilizaremos o GitHub Pages.

O GitHub Pages permite transformar um repositório do GitHub em um site acessível pela Internet.

7.1 CONFIGURANDO A PUBLICAÇÃO

Passo 1 – Abrir o repositório

Entre no GitHub e abra o repositório onde estão os arquivos do relatório.

Por exemplo:

Profmatma41

Passo 2 – Abrir as configurações

Dentro do repositório, clique em:

Settings

Depois, procure no menu lateral a opção:

Pages

Passo 3 – Escolher a forma de publicação

Na área Build and deployment, procure a opção Source.

Selecione:

Deploy from a branch

Depois, selecione:

Branch: main

E, na pasta, escolha:

/(root)

Depois clique em:

Save

O GitHub começará a publicar o projeto.

7.2 ACESSANDO O RELATÓRIO PELA INTERNET

Depois de configurar o GitHub Pages, o GitHub disponibilizará um endereço para acessar a página.

Dentro de:

Settings → Pages

será possível verificar o endereço do site publicado.

Clique no endereço disponibilizado pelo GitHub para abrir o relatório.

Agora o relatório poderá ser visualizado diretamente pelo navegador.

8. RESULTADOS ESPERADOS

Ao finalizar todas as etapas, espera-se que a pessoa consiga:

  • criar um projeto no RStudio;
  • criar um relatório utilizando R Markdown;
  • escrever textos no relatório;
  • inserir códigos simples em R;
  • gerar o relatório utilizando o botão Knit;
  • criar uma conta no GitHub;
  • criar um repositório;
  • enviar os arquivos do projeto para o GitHub utilizando o Git;

O principal resultado esperado é que uma pessoa que nunca teve contato com programação consiga compreender o processo e realizar as etapas seguindo as instruções apresentadas.

Primeiramente, foi criado um projeto no RStudio e, em seguida, foi elaborado um relatório utilizando R Markdown. Foram apresentados exemplos de textos e códigos simples, mostrando como o R pode ser utilizado para realizar cálculos e apresentar resultados.

Depois, foi explicado como utilizar o Git para registrar as alterações e enviar os arquivos para o GitHub. Por fim, foi apresentado o GitHub Pages, utilizado para disponibilizar o relatório na Internet.

Dessa forma, foi possível perceber que, mesmo para uma pessoa que não possui conhecimentos de programação, é possível aprender a criar e publicar um relatório seguindo cada etapa de maneira organizada.
