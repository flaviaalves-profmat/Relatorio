Introdução Este relatório apresenta uma análise estatística de um banco de dados composto por 1.000 alunos de uma escola pública brasileira. O banco de dados foi elaborado para proporcionar uma experiência prática de análise estatística, envolvendo informações relacionadas à frequência escolar, ao desempenho acadêmico e a características sociofamiliares dos estudantes. São analisadas cinco variáveis: número de faltas, nota média, turno de estudo, escolaridade da mãe e acesso à internet em casa. O objetivo deste trabalho é explorar os dados, identificar possíveis relações entre as variáveis e responder às questões investigativas propostas, buscando compreender fatores associados ao desempenho escolar. # 2. Banco de dados O banco de dados utilizado neste relatório é o arquivo `dados_alunos.csv`. As variáveis analisadas são: * **Faltas:** número de ausências do aluno durante o ano letivo; * **Nota média:** desempenho acadêmico médio do aluno; * **Turno:** período em que o aluno estuda; * **Escolaridade da mãe:** nível de escolaridade da mãe; * **Acesso à internet:** informação sobre a existência de acesso à internet em casa. Segundo a descrição fornecida, a variável faltas é quantitativa discreta, a nota média é quantitativa contínua, o turno é qualitativo nominal, a escolaridade da mãe é qualitativa ordinal e o acesso à internet é qualitativo nominal. ## 2.1 Importação dos dados O banco de dados será importado utilizando o separador `;` e o ponto como separador decimal. ```{r} dados_alunos <- read.table( file = "dados_alunos.csv", header = TRUE, sep = ";", dec = ".", stringsAsFactors = FALSE ) ``` Para verificar as primeiras linhas do banco: ```{r} head(dados_alunos) ``` Também podemos verificar a quantidade de linhas e colunas: ```{r} dim(dados_alunos) ``` O banco possui `r nrow(dados_alunos)` alunos e `r ncol(dados_alunos)` variáveis. Os nomes das variáveis são: ```{r} names(dados_alunos) ``` # 3. Análise Univariada A análise univariada consiste em observar cada variável individualmente. Inicialmente serão analisadas as variáveis quantitativas e, em seguida, as variáveis qualitativas. ## 3.1 Número de faltas A variável número de faltas representa a quantidade de ausências de cada aluno durante o ano letivo. Trata-se de uma variável quantitativa discreta. ### Medidas estatísticas ```{r} summary(dados_alunos$faltas) ``` A média de faltas dos alunos é: ```{r} mean(dados_alunos$faltas) ``` A mediana é: ```{r} median(dados_alunos$faltas) ``` O desvio-padrão é: ```{r} sd(dados_alunos$faltas) ``` A média de faltas observada foi de **`r round(mean(dados_alunos$faltas), 2)` faltas**, enquanto a mediana foi de **`r round(median(dados_alunos$faltas), 2)` faltas**. O menor número de faltas observado foi de **`r min(dados_alunos$faltas)`**, e o maior foi de **`r max(dados_alunos$faltas)`**. ### Distribuição das faltas ```{r} hist( dados_alunos$faltas, main = "Distribuição do Número de Faltas", xlab = "Número de faltas", ylab = "Quantidade de alunos" ) ``` O histograma permite observar como o número de faltas está distribuído entre os alunos. ## 3.2 Nota média A nota média representa o desempenho acadêmico dos alunos e é uma variável quantitativa contínua. ### Medidas estatísticas ```{r} summary(dados_alunos$nota_media) ``` A média das notas é: ```{r} mean(dados_alunos$nota_media) ``` A mediana é: ```{r} median(dados_alunos$nota_media) ``` O desvio-padrão é: ```{r} sd(dados_alunos$nota_media) ``` A nota média geral dos alunos foi de **`r round(mean(dados_alunos$nota_media), 2)` pontos**, enquanto a mediana foi de **`r round(median(dados_alunos$nota_media), 2)` pontos**. A menor nota observada foi **`r min(dados_alunos$nota_media)`** e a maior foi **`r max(dados_alunos$nota_media)`**. ### Distribuição das notas ```{r} hist( dados_alunos$nota_media, main = "Distribuição das Notas Médias", xlab = "Nota média", ylab = "Quantidade de alunos" ) ``` O histograma permite visualizar a distribuição das notas médias dos estudantes. ## 3.3 Turno de estudo A variável turno é qualitativa nominal e possui as categorias matutino, vespertino e noturno. ### Frequência por turno ```{r} table(dados_alunos$turno) ``` ### Percentual por turno ```{r} round(prop.table(table(dados_alunos$turno)) * 100, 2) ``` ### Gráfico ```{r} barplot( table(dados_alunos$turno), main = "Distribuição dos Alunos por Turno", xlab = "Turno", ylab = "Quantidade de alunos" ) ``` O gráfico apresenta a distribuição dos estudantes entre os diferentes turnos. ## 3.4 Escolaridade da mãe A escolaridade da mãe é uma variável qualitativa ordinal, pois suas categorias possuem uma ordem natural: Fundamental, Médio e Superior. ### Frequência ```{r} table(dados_alunos$escolaridade_mae) ``` ### Percentual ```{r} round(prop.table(table(dados_alunos$escolaridade_mae)) * 100, 2) ``` ### Gráfico ```{r} barplot( table(dados_alunos$escolaridade_mae), main = "Escolaridade das Mães dos Alunos", xlab = "Escolaridade da mãe", ylab = "Quantidade de alunos" ) ``` A distribuição apresentada permite conhecer o nível de escolaridade das mães dos alunos participantes do banco. ## 3.5 Acesso à internet em casa O acesso à internet é uma variável qualitativa nominal com duas categorias: Sim e Não. ### Frequência ```{r} table(dados_alunos$acesso_internet) ``` ### Percentual ```{r} round(prop.table(table(dados_alunos$acesso_internet)) * 100, 2) ``` ### Gráfico ```{r} barplot( table(dados_alunos$acesso_internet), main = "Acesso à Internet em Casa", xlab = "Acesso à internet", ylab = "Quantidade de alunos" ) ``` A análise permite verificar a proporção de alunos que possuem e que não possuem acesso à internet em casa. # 4. Análise Bivariada Na análise bivariada são estudadas relações entre duas variáveis. O objetivo é verificar possíveis associações entre características dos alunos e seu desempenho acadêmico. ## 4.1 Acesso à internet e nota média Uma das questões propostas é verificar se os alunos com acesso à internet em casa apresentam notas médias maiores. Primeiramente, calculamos a média das notas para cada grupo. ```{r} media_internet <- tapply( dados_alunos$nota_media, dados_alunos$acesso_internet, mean ) round(media_internet, 2) ``` As médias também podem ser visualizadas por meio de um boxplot. ```{r} boxplot( nota_media ~ acesso_internet, data = dados_alunos, main = "Nota Média por Acesso à Internet", xlab = "Acesso à internet", ylab = "Nota média" ) ``` Para verificar estatisticamente a diferença entre os dois grupos, será realizado um teste t. ```{r} teste_internet <- t.test( nota_media ~ acesso_internet, data = dados_alunos ) teste_internet ``` O nível de significância adotado será de 5%. ```{r} teste_internet$p.value ``` A diferença entre as médias dos grupos apresentou valor de p igual a **`r round(teste_internet$p.value, 4)`**. ```{r} if(teste_internet$p.value < 0.05) { cat("Como o valor de p é menor que 0,05, há evidências estatísticas de diferença entre as notas médias dos alunos com e sem acesso à internet.") } else { cat("Como o valor de p é maior ou igual a 0,05, não há evidências estatísticas suficientes para afirmar que as notas médias dos dois grupos sejam diferentes.") } ``` Assim, os resultados permitem avaliar se o acesso à internet está associado a diferenças estatisticamente significativas no desempenho dos alunos. ## 4.2 Escolaridade da mãe e desempenho A segunda questão investiga como a escolaridade da mãe se relaciona com o desempenho dos alunos. Vamos calcular a nota média para cada nível de escolaridade. ```{r} media_escolaridade <- tapply( dados_alunos$nota_media, dados_alunos$escolaridade_mae, mean ) round(media_escolaridade, 2) ``` O resultado também será apresentado graficamente. ```{r} boxplot( nota_media ~ escolaridade_mae, data = dados_alunos, main = "Nota Média por Escolaridade da Mãe", xlab = "Escolaridade da mãe", ylab = "Nota média" ) ``` Para verificar se existem diferenças estatisticamente significativas entre as médias dos grupos, será utilizada uma análise de variância (ANOVA). ```{r} modelo_anova <- aov( nota_media ~ escolaridade_mae, data = dados_alunos ) summary(modelo_anova) ``` O valor de p obtido é: ```{r} anova_resultado <- summary(modelo_anova)[[1]] p_anova <- anova_resultado[["Pr(>F)"]][1] p_anova ``` ```{r} if(p_anova < 0.05) { cat("O valor de p é menor que 0,05. Portanto, existem evidências de diferença entre as médias de notas dos grupos de escolaridade materna.") } else { cat("O valor de p é maior ou igual a 0,05. Portanto, não há evidências estatísticas suficientes de diferença entre as médias de notas dos grupos de escolaridade materna.") } ``` Essa análise permite verificar se a escolaridade materna está associada a diferenças no desempenho acadêmico. ## 4.3 Número de faltas e nota média Outra questão importante é verificar a relação entre frequência escolar e desempenho. Primeiramente, será calculado o coeficiente de correlação. ```{r} correlacao <- cor( dados_alunos$faltas, dados_alunos$nota_media ) correlacao ``` O coeficiente de correlação encontrado foi **`r round(correlacao, 3)`**. Para visualizar essa relação: ```{r} plot( dados_alunos$faltas, dados_alunos$nota_media, main = "Relação entre Número de Faltas e Nota Média", xlab = "Número de faltas", ylab = "Nota média" ) abline( lm(nota_media ~ faltas, data = dados_alunos) ) ``` Também será realizado um teste de correlação. ```{r} teste_correlacao <- cor.test( dados_alunos$faltas, dados_alunos$nota_media ) teste_correlacao ``` ```{r} if(correlacao < 0) { cat("A correlação encontrada é negativa. Isso indica que, de modo geral, maiores números de faltas estão associados a menores notas médias.") } else if(correlacao > 0) { cat("A correlação encontrada é positiva. Isso indica que, de modo geral, maiores números de faltas estão associados a maiores notas médias.") } else { cat("A correlação encontrada é aproximadamente nula, indicando pouca ou nenhuma associação linear entre faltas e nota média.") } ``` ### Investigação de um possível ponto crítico Para investigar se existe uma mudança importante no desempenho conforme aumentam as faltas, podemos comparar as notas médias por faixas de faltas. ```{r} dados_alunos$faixa_faltas <- cut( dados_alunos$faltas, breaks = c(-1, 5, 10, 15, 20, 30), labels = c( "0 a 5", "6 a 10", "11 a 15", "16 a 20", "21 a 30" ) ) ``` Agora calculamos as médias: ```{r} tapply( dados_alunos$nota_media, dados_alunos$faixa_faltas, mean ) ``` E fazemos o gráfico: ```{r} boxplot( nota_media ~ faixa_faltas, data = dados_alunos, main = "Nota Média por Faixa de Faltas", xlab = "Faixa de faltas", ylab = "Nota média" ) ``` Essa análise permite observar se há uma redução mais acentuada das notas em alguma faixa específica de faltas. ## 4.4 Turno e número de faltas A análise seguinte verifica se os alunos do turno noturno apresentam maior número de faltas. ```{r} media_faltas_turno <- tapply( dados_alunos$faltas, dados_alunos$turno, mean ) round(media_faltas_turno, 2) ``` O gráfico permite comparar visualmente os grupos. ```{r} boxplot( faltas ~ turno, data = dados_alunos, main = "Número de Faltas por Turno", xlab = "Turno", ylab = "Número de faltas" ) ``` O turno com maior número médio de faltas foi: ```{r} names(which.max(media_faltas_turno)) ``` com média de **`r round(max(media_faltas_turno), 2)` faltas. ## 4.5 Turno e nota média Também será analisado o desempenho dos alunos de acordo com o turno. ```{r} media_nota_turno <- tapply( dados_alunos$nota_media, dados_alunos$turno, mean ) round(media_nota_turno, 2) ``` Gráfico: ```{r} boxplot( nota_media ~ turno, data = dados_alunos, main = "Nota Média por Turno", xlab = "Turno", ylab = "Nota média" ) ``` O turno que apresentou a maior nota média foi **`r names(which.max(media_nota_turno))`**, com média de **`r round(max(media_nota_turno), 2)`**. O turno que apresentou a menor nota média foi **`r names(which.min(media_nota_turno))`**, com média de **`r round(min(media_nota_turno), 2)`**. # 5. Análise Multivariada Nesta etapa, serão consideradas conjuntamente três variáveis: turno, acesso à internet e nota média. O objetivo é observar se os padrões de desempenho variam quando essas características são analisadas simultaneamente. ## 5.1 Turno, acesso à internet e nota média Primeiramente, serão calculadas as médias das notas para cada combinação de turno e acesso à internet. ```{r} media_conjunta <- aggregate( nota_media ~ turno + acesso_internet, data = dados_alunos, FUN = mean ) media_conjunta ``` Também podemos organizar essas informações em uma tabela: ```{r} tabela_conjunta <- xtabs( nota_media ~ turno + acesso_internet, data = dados_alunos ) round(tabela_conjunta, 2) ``` Para visualizar os resultados: ```{r} boxplot( nota_media ~ turno + acesso_internet, data = dados_alunos, main = "Nota Média por Turno e Acesso à Internet", xlab = "Combinação entre turno e acesso à internet", ylab = "Nota média" ) ``` A análise conjunta permite observar se o efeito associado ao acesso à internet apresenta comportamento semelhante nos diferentes turnos. # 6. Síntese dos resultados A análise realizada permitiu investigar as principais características do banco de dados e as relações entre as variáveis estudadas. Em relação às faltas, a média observada foi de **`r round(mean(dados_alunos$faltas), 2)`**, enquanto a nota média geral dos alunos foi de **`r round(mean(dados_alunos$nota_media), 2)`**. A análise do acesso à internet permitiu comparar o desempenho dos alunos que possuem e que não possuem acesso em casa. A escolaridade da mãe também foi analisada em relação ao desempenho acadêmico, permitindo verificar se existem diferenças entre os grupos Fundamental, Médio e Superior. A relação entre faltas e notas foi investigada por meio do coeficiente de correlação. O valor encontrado foi **`r round(correlacao, 3)`**, indicando uma associação linear **`r if(correlacao < 0) "negativa" else if(correlacao > 0) "positiva" else "próxima de zero"`**. Também foi possível comparar o número de faltas e as notas médias entre os diferentes turnos de estudo. Por fim, a análise conjunta entre turno, acesso à internet e nota média permitiu observar padrões que poderiam não ser percebidos quando as variáveis são analisadas separadamente. # 7. Respostas às questões investigativas ## Questão 1 – Acesso à internet e desempenho Os dados foram utilizados para verificar se alunos com acesso à internet em casa apresentam notas médias maiores. A média das notas dos alunos com acesso à internet foi: ```{r} mean(dados_alunos$nota_media[dados_alunos$acesso_internet == "Sim"]) ``` A média das notas dos alunos sem acesso à internet foi: ```{r} mean(dados_alunos$nota_media[dados_alunos$acesso_internet == "Não"]) ``` A comparação e o teste estatístico realizado permitem verificar se a diferença observada é estatisticamente significativa. ## Questão 2 – Capital cultural e rendimento A escolaridade da mãe foi relacionada às notas médias dos alunos. A comparação das médias entre os níveis Fundamental, Médio e Superior permite identificar se existe um padrão de crescimento ou redução do desempenho conforme aumenta a escolaridade materna. ```{r} round(media_escolaridade, 2) ``` Os resultados devem ser interpretados juntamente com a análise de variância realizada anteriormente. ## Questão 3 – Frequência e desempenho A correlação entre faltas e notas foi de **`r round(correlacao, 3)`**. ```{r} if(correlacao < -0.5) { cat("O resultado indica uma associação negativa relativamente forte entre faltas e nota média.") } else if(correlacao < -0.3) { cat("O resultado indica uma associação negativa moderada entre faltas e nota média.") } else if(correlacao < 0) { cat("O resultado indica uma associação negativa, embora de menor intensidade.") } else if(correlacao > 0.5) { cat("O resultado indica uma associação positiva relativamente forte entre faltas e nota média.") } else if(correlacao > 0.3) { cat("O resultado indica uma associação positiva moderada entre faltas e nota média.") } else { cat("O resultado indica uma associação linear fraca ou próxima de zero entre faltas e nota média.") } ``` A análise por faixas de faltas também foi utilizada para investigar a existência de um possível ponto a partir do qual o desempenho apresenta alteração mais acentuada. ## Questão 4 – Perfil do aluno noturno Os dados foram utilizados para comparar o número médio de faltas entre os turnos. ```{r} round(media_faltas_turno, 2) ``` Dessa forma, é possível verificar se o turno noturno apresenta maior número médio de faltas e comparar seu desempenho com os demais turnos. ## Questão 5 – Desigualdades educacionais As variáveis escolaridade da mãe e acesso à internet foram analisadas em relação à nota média. Os resultados permitem identificar possíveis diferenças de desempenho entre grupos com diferentes condições sociofamiliares. Entretanto, é importante destacar que a existência de associação entre duas variáveis não significa necessariamente que uma delas seja a causa da outra. ## Questão 6 – Análise por subgrupos A análise conjunta entre turno e acesso à internet permite observar como as notas médias se comportam em diferentes combinações dessas duas características. ```{r} media_conjunta ``` Essa análise possibilita identificar padrões específicos dentro dos subgrupos de alunos. # 8. Conclusão A análise estatística do banco de dados permitiu explorar informações de 1.000 alunos e investigar relações entre frequência escolar, desempenho acadêmico e características sociofamiliares. A análise univariada possibilitou conhecer individualmente as cinco variáveis estudadas. Foram calculadas medidas estatísticas para as variáveis quantitativas e frequências e gráficos para as variáveis qualitativas. Na análise bivariada, foram investigadas relações entre acesso à internet e desempenho, escolaridade da mãe e nota média, faltas e desempenho, além de diferenças entre os turnos de estudo. A análise das faltas e das notas mostrou uma correlação de **`r round(correlacao, 3)`**, permitindo avaliar a existência de associação entre frequência escolar e desempenho acadêmico. A análise multivariada, considerando conjuntamente turno, acesso à internet e nota média, ampliou a compreensão dos dados e permitiu observar diferentes padrões entre os subgrupos. De maneira geral, o estudo demonstra a importância da estatística como ferramenta para compreender situações educacionais. A análise de dados pode auxiliar professores e gestores na identificação de padrões e na reflexão sobre fatores relacionados à frequência e ao desempenho dos estudantes. # 9. Limitações da análise Embora o banco de dados possibilite diversas análises, ele possui apenas cinco variáveis. Outros fatores que podem estar relacionados ao desempenho escolar não estão presentes no conjunto de dados. Além disso, os resultados apresentados indicam associações entre variáveis, mas não permitem afirmar relações de causa e efeito. Outra limitação é que os dados foram construídos para uma situação de pesquisa simulada, não representando necessariamente toda a realidade das escolas públicas brasileiras. # 10.
